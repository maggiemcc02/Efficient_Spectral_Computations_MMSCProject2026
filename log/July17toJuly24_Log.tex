\subsection{Meeting notes}

\begin{itemize}
    \item Do not focus on perfect code. Get it working for the folded eigenproblem (or self-adjoint eigenproblems).
    \item For the alignment code, do not use the m-form. For the folded problem and the standard Poisson, use $L^2-L^2.$ For the mixed formulation, use $L^2-H(\operatorname{div}).$
    \item \checkmark Make sure the initial guess continuation is working as expected. We may not expect to see a reflection of eigenfunctions across meshes if it is. 
    \item Rate of convergence for eigenvalues on L-shaped mesh should be $ N^ {- 1}.$ We need to debug the code to achieve this.
    \item \checkmark Use mixed formulation of Poisson that perfectly aligns with the primal formulation (CG, DG). Make sure we get the same results as if we used the primal formulation. This should test adaptivity.
    \item Get it working on the L-shaped domain first.
    \item \checkmark Make things explicit, for example, make the markers real, to avoid these complex warnings.
    \item The dual error being $z_h^+ - z_h$ is intentional. It has to do with algebraic errors and being able to separate out the discretization errors. This happened after Rognes and Logg with Rannacher in/near 2011. Check out the estimator review sent out by Patrick and track down the paper. For the most effective localization (not thinking of algebraic errors), you want $(z_h \in V_h^+) - (p \in V_h)$ to be small so that where it is large on the mesh is a good signal. This motivates taking $z_h^+ - I_h^+ z_h$ because we expect $I_h z_h^+$ to be the closest thing to $z_h^+$ in $V_h.$ Pablo lets the user decide which version of the dual error they want to use. I will compare both to see how much of a difference it makes. At the global level (global error estimate), it does not matter because of Galerkin orthogonality. 
    \item Once we get adaptivity working, we will play around with it to see what criteria best indicates the need for adaptivity. A first problem should be Poisson, where we know the pseudospectral contours, the eigenvalues, etc. 
    \item Make a thesis document and start thinking about its structure and the background material. Kathryn probably has a template, or the OCIAM template (Keith Gillow) is popular.
    \item Next meeting is 4 pm next Friday (July 24).
\end{itemize}

\section{Daily Logs}


\textbf{Monday}
\begin{enumerate}
    \item More iterations of adaptation for L-shaped Poisson example. I get desired convergence for dof $> 10^3$ (after approx. seven adaptations). I need to decide if this result is good, in that we eventually obtain the desired convergence rate, or bad, in that it takes too long to obtain the desired convergence rate. 
    \item Compared mixed and primal (CG1-DG0) poisson on L-shaped domain and they match (up to almost machine precision).
    \item Compared $z_h^+ - I_h z_h^+$ to $z_h^+ - z_h.$ They behave similarly.
    \item Compared adaptivity to uniform refinement (5 levels of mesh hierarchy). Uniform refinement yielded worse results (rate approx. 0.7) as expected. However, I am not sure if this is a great test for comparison (hierarchy DOF vs adaptivity DOF and adaptivity takes a while to do well).
    \item Thesis outline started. 
\end{enumerate}


\textbf{Tuesday}
\begin{enumerate}
\item Ran a few more quick tests for the convergence rate as a part of a Slack discussion with Umberto.
\item Tried to find a reference with the $N^{-1/2}$ result for the L-shaped domain. Umberto later sent one.
\item Located Rannacher's talk and paper about seperating the discretization error and the iteration error in a posteriori error estimates. This supports choosing $z_h^+ - z_h$ in the local error estimates. I spent a few hours going through the talk and the paper.
\item Worked a bit more on my thesis outline, went through the advice sent around by Kathryn, and I started going back over Nick's text on Spectra and Pseudospectra, which I expect to be in the background and introduction of my final report. 
\item Reference for convergenc rate: \textit{An oscillation-free adaptive FEM for symmetric
eigenvalue problems by Carsten Carstensen and Joscha Gedicke}. Figure 6 in that paper suggests that they also did not attain the desired convergence results until $DOF > 10^3.$
\end{enumerate}

    \item Met with Umberto to begin discussing the structure of the inner and outer loops.
